Wie soll Karo Claude erreichen?

Zum Weitergeben: Anthropic erlaubt Entwicklern nicht, das eigene claude.ai-Konto für ein Produkt anzubieten. Wenn Ihr Freund Karo mit seinem eigenen Abo und seinem eigenen Token benutzt, ist das etwas anderes — er verbraucht sein Kontingent, nicht Ihres. Für ein verkauftes Produkt bleibt der API-Schlüssel der vorgesehene Weg.

Token aus dem Abo

So kommen Sie an den Token — einmal am Rechner, im Terminal:

npm install -g @anthropic-ai/claude-code   # falls noch nicht da
claude auth login                          # mit Ihrem Abo anmelden
claude setup-token                         # Token wird angezeigt

Der Token wird sofort mit einem echten Aufruf geprüft und nur bei Erfolg gespeichert.
