# Synthetische Proben für die CI

Hier liegen **keine echten Schulblätter** und kein Text daraus. `erzeugen.py`
baut drei Dateien aus dem Nichts: ein gerendertes Foto, ein PDF mit Textebene
und ein PDF ohne. Sie beantworten eine Frage: *geht der Weg überhaupt durch?*

Wie gut Karo wirklich liest, misst `make ocr-report` auf dem Rechner der
Familie an deren eigenen Blättern. Diese bleiben dort — ins Repository kommt
nur die Kennzahl (`docs/OCR_TREFFERQUOTE.md`). Eine Trefferquote über
synthetische Bilder wäre eine Zahl über nichts: sie sagt, dass Karo seine
eigene Schrift lesen kann.
